# Tpcool's Cave Story Assembly Hacks
As I begin to unleash the power of assembly hacking in Cave Story, I will publish my progress to this repository. These hacks are written with the Doukutsu Assembler in mind to make them easier to write and maintain. I anticipate that my early output will focus primarily on NPC hacks. This will include:
- Optimized vanilla NPC code
- Custom NPC code with a vanilla NPC as the base
- Completely original NPC code (well the code might be original but the NPC itself will probably be derived from something funny)

The optimized vanilla NPC code will serve as a great baseline for myself and others to make their own quick modifications to vanilla NPCs without trudging through the original code. The main point is to allow me to bend them to my will more effectively, after all...
